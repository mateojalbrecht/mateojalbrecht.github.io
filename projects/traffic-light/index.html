PROJECT NOTES

FPGA Traffic Light Controller

A traffic controller for a highway–farm road intersection. The design prioritizes highway traffic and responds to a farm-road sensor, using timed states to control the sequence of signals.

01

Control behavior

The controller uses a Mealy finite state machine and counters for timed light transitions. After at least 30 seconds in highway green, a farm-road sensor request can trigger the transition to yellow. When the farm-road sensor clears during farm green, the controller begins the return sequence.

02

Implementation

  • Wrote the controller in behavioral Verilog.
  • Mapped a pushbutton to the farm-road sensor and LEDs to the two traffic signals.
  • Used Vivado XDC constraints to map the logic to physical FPGA pins.
  • Simulated the logic and tested the controller on the Zybo Z7-10 development board.
03

Design artifact

The original state sketch documents the controller transitions and timing conditions.
