PROJECT NOTES

Docker Home Server

A practical infrastructure project that extends the useful life of an older desktop. Ubuntu Server and Docker provide a common platform for managing home services from one machine.

01

The system

Installed Ubuntu Server on a repurposed Dell desktop and connected it over Ethernet. Configured containerized services with Docker Compose to separate service configuration and simplify ongoing management.

02

Services and integration

  • Pi-hole for DNS filtering across the home network.
  • Plex for personal media streaming.
  • Homebridge for connecting devices to the Apple smart home ecosystem.
  • Retro gaming services as part of the original home-server setup.
03

Practical outcome

Brought networking, media, and home automation services together on existing hardware. The project provided experience with Linux administration, container configuration, and service access on a local network.
