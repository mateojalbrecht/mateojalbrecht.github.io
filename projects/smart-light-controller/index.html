PROJECT NOTES

IoT Smart Light Controller

An end-to-end hardware and software project for remotely operating a motorized lighting system. It brings together embedded control logic, cloud state synchronization, mobile automation, and a custom physical mount.

01

The engineering challenge

Connect a physical actuator to a remote interface while coordinating the embedded device, cloud data flow, and mobile automation.

02

What I built

  • ESP32-based motor control firmware in C++.
  • Firebase cloud synchronization for remote operation, with REST API integration.
  • iOS automation written in Swift.
  • A custom CAD-designed, 3D-printed servo mount.
03

Integration and validation

Validated the end-to-end connection between mobile automation, cloud synchronization, embedded logic, and the mechanical actuator. The project combined software development with the practical constraints of mounting and operating a motor.
