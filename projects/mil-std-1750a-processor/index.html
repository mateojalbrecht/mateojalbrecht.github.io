PROJECT NOTES

MIL-STD-1750A Processor

A senior capstone exploring the full digital design process: from synthesizable RTL and verification to synthesis, timing analysis, and physical implementation. The team is developing a MIL-STD-1750A-compatible processor; implementation and verification are ongoing.

01

The engineering challenge

Build a synthesizable 16-bit processor with a five-stage pipeline, while aligning instruction and data memory behavior with the datapath and control interfaces. The project targets SKY130 ASIC implementation.

02

My contribution

  • Designing and verifying the 16-bit instruction and data memory RTL.
  • Creating testbenches for instruction fetch, memory reads, and clocked writes.
  • Integrating memory interfaces with the processor datapath and control logic in a three-member team.
03

Implementation workflow

Applying Yosys for logic synthesis, OpenSTA for static timing analysis, and OpenROAD for physical implementation. The work includes area evaluation and development of an RTL-to-GDSII flow.

04

ALU implementation

The team status presentation documents my ALU implementation in Verilog, supporting arithmetic, logical, and shift operations. The module went through SKY130HD synthesis, placement, clock-tree synthesis, and global routing. Timing optimization remains in progress.

05

Data memory interface

The data memory subsystem uses clocked writes and combinational reads. This module diagram shows its address, data, clock, and read/write control interfaces.

06

Current status

Currently designing and verifying memory RTL, integrating processor interfaces, and developing the implementation flow. The capstone is scheduled to conclude in May 2027.
